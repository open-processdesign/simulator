# Code of conduct

Open Process Design is built by students, teachers and engineers with very different backgrounds and levels of experience. We want everyone to be able to take part.

**We expect:**

- Respect and patience, especially with newcomers and with questions that seem basic.
- Disagreement about ideas, never about people. Use data and sources to settle technical questions.
- Credit: name the sources of data, equations and code you use.
- Care with results: say clearly when something is approximate, unvalidated or outside a model's range.

**Not acceptable:** harassment, insults, discriminatory remarks, personal attacks, publishing others' private information, or pressure to accept changes.

**Reporting:** write to the maintainer (see the repository owner on GitHub). Reports are handled confidentially. The maintainer may remove content and restrict participation for behaviour that breaks these rules.
